# V3 Keyboard Alpha 0.1

This alpha is the first cohesive live-test build after the Stage 19 language-chooser work.

## Included

- EN / DE / UK / RU layouts
- Shift / Caps Lock and symbols
- bottom-row Globe language cycling
- long-press Globe or Space language chooser
- long-press alternates: `ß`, `ґ`, `ё` and uppercase variants
- Clipboard panel using the current Wayland/Qt clipboard
- basic Emoji panel
- Text editing panel with cursor/home/end/delete/backspace controls
- Settings panel with Dark/AMOLED, key size, borders and popups
- QSettings persistence for language and appearance preferences

## Live-test focus

The build is intended for real V3 tablet use. The next work should be driven by reproducible live bugs and ergonomics found on-device, then followed by the prediction/autocorrect subsystem.
