# V3 Keyboard v0.2 — Smart typing completion spec

Status: approved by the standing project roadmap and the user's instruction to finish the keyboard functionality cohesively.

## Product constraints
- Wayland-native, Plasma/KWin-first, compositor-agnostic core.
- No Google services, telemetry, cloud language model, or network dependency.
- Preserve the known-good KWin input-method-v1/input-panel-v1 transport.
- EN/DE/UK/RU remain first-class languages.
- Gboard-like interaction model without copying proprietary assets/code.

## This milestone
1. Local dictionary service that loads system Hunspell dictionaries when available and has a small built-in fallback vocabulary.
2. Prefix suggestions and one-edit typo corrections.
3. Per-language local learning and previous-word bigram ranking in QSettings.
4. Current-word tracking, suggestion strip, suggestion replacement, auto-correct on space, auto-capitalization, and double-space period.
5. User toggles for suggestions, autocorrect, learning, auto-capitalization, and double-space period.
6. Persistent clipboard history with dedupe, delete, clear, and tap-to-paste.
7. Emoji catalog with categories plus local search; use the system Unicode emoji-test data when present and curated fallback otherwise.
8. Cursor swipe on Space and accelerated Backspace hold/drag hooks in the UI.
9. Core APIs for glide traces and a dictionary-backed glide decoder; QML integration is included where it can be done without destabilizing tap typing.

## Deferred after this milestone
- wlroots input-method-v2 / virtual-keyboard-v1 backend.
- true floating input-panel placement (requires compositor-specific/windowing work).
- richer full CLDR localized emoji keywords when not supplied by the OS.
- handwriting/voice input.
